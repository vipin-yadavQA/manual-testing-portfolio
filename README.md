# Manual Testing Portfolio

Welcome to my Manual Testing Portfolio!

I am a Software QA Engineer with **5+ years of experience** in software testing. This repository showcases sample QA documentation and practical testing deliverables covering manual testing concepts and real-world testing scenarios.

## About This Repository

This portfolio demonstrates my understanding of software testing processes, test documentation, defect reporting, test execution, and test planning.

## Repository Structure

| Folder | Description |
|---|---|
| `Test-Cases` | Sample test cases for application features |
| `Test-Scenarios` | High-level test scenarios |
| `Bug-Reports` | Sample defect reports with steps to reproduce |
| `Test-Plan` | Sample test plan and testing approach |
| `Test-Execution-Reports` | Illustrative test execution results |
